# Comparing Matplotlib and Seaborn with Tips Dataset

> **Project URL:** https://roadmap.sh/projects/data-visualization-tutorial

## 📌 Project Overview
Project ini membandingkan teknik visualisasi data menggunakan **Matplotlib** dan **Seaborn** pada dataset `tips` bawaan Seaborn.

## 📊 Visualisasi yang Dibuat
1. **Histogram**: Distribusi total tagihan (*total bill*).
2. **Bar Chart**: Rata-rata total tagihan per hari.
3. **Box Plot**: Sebaran total tagihan berdasarkan hari.
4. **Scatter Plot**: Hubungan antara total tagihan dan tip.
5. **Heatmap**: Korelasi antar variabel numerik.

## 🛠️ Tools & Library
- Python 3
- Pandas, Matplotlib, Seaborn
- Google Colab / Jupyter Notebook
